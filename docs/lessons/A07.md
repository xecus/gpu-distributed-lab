# A07 — PyTorch DDPとDistributedSampler

GPU：2〜8。実行場所：承認済みAWS GPUホスト、リポジトリroot。

## 1. 理論・アルゴリズム

DDPはautograd hookで勾配の準備完了を検知し、bucket単位のAllReduceをbackwardと重ねる。DistributedSamplerは固定indexed corpusをrankへ分け、seedとset_epochで再現可能なshuffleを行う。
本教材は65536個のindexed windowをSamplerで分割する。global batchが一定でもGPU数によりサンプルの順序は変わりうるが、同じ分布を処理する。全rankが等micro数で参加しないとcollectiveが待ち続ける。

共通の数式・メモリモデル：[theory.md](../theory.md)。
