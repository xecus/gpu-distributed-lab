# A01 — GPUアーキテクチャ・CUDA基礎

GPU：1。実行場所：承認済みAWS GPUホスト、リポジトリroot。

## 1. 理論・アルゴリズム

GPU（H100/H200はHopper、B200はBlackwell）のSMは複数のwarpを実行し、Tensor Coreは対応精度の行列積を高速化する。HBMはモデル/activationを保持する主記憶。GPU演算は非同期なのでPythonのmatmul直後のtimeだけでは測れない。
正方行列積の演算数は2n³、入力/出力の最小転送量は約3n²×dtype bytes。nが小さいとlaunch overhead、大きいとcomputeが支配する。ここではTF32を無効にしてFP32とBF16を比較する。CUDA Eventのelapsed_timeとsynchronizeを使う。

共通の数式・メモリモデル：[theory.md](../theory.md)。

## 5. 期待結果

大きいGEMMでBF16の時間短縮とメモリ削減が期待される。小GEMMではピークTFLOPsに近づかない。速度比の数値は実機測定前なので規定しない。

ここは検証前の仮説であり、GPUの実測値ではない。各条件でwarmupを除き、同じ条件を再試行してばらつきを確認する。
